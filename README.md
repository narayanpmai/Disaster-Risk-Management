# विपद् जोखिम व्यवस्थापन तथा बहुक्षेत्रीय जोखिम मूल्याङ्कन प्रणाली
## Disaster Risk Management & Multi-Sectoral Risk Assessment System (DRM-MSRA)

नेपालका स्थानीय तह (गाउँपालिका तथा नगरपालिका) हरूका लागि लक्षित **जोखिमयुक्त बस्ती तथा पूर्वाधार आयोजनाहरूको वैज्ञानिक पहिचान, संवेदनशीलता विश्लेषण र विपद् जोखिम न्यूनीकरण** का लागि विकसित अत्याधुनिक, एकीकृत ३डी/जीआईएस डिजिटल ट्विन तथा एआई-सञ्चालित प्रणाली।

---

## 🎯 मुख्य उद्देश्य र कार्यक्षेत्र (Core Mission & Scope)

नेपालको भौगोलिक बनावट, जलवायु परिवर्तनको असर, बाढी, पहिरो, भूकम्प, र नदीजन्य उत्खननका कारण प्रत्येक वर्ष हुने जनधन र भौतिक पूर्वाधारको क्षति रोक्न यो प्रणाली निर्माण गरिएको हो।
- **जोखिमयुक्त बस्ती पहिचान (Hazard-Prone Settlements):** भिरालो जमिन, गेग्रान बहाव, नदी कटान तथा हिमनदी ताल (GLOF) जोखिम क्षेत्रमा रहेका बस्तीहरूको ३डी/जीआईएस नक्साङ्कन, जनसांख्यिकीय संवेदनशीलता (SVI) मापन र स्थानान्तरण योजना।
- **जोखिमयुक्त पूर्वाधार आयोजना पहिचान (At-Risk Infrastructure Screening):** सडक, पुल, खानेपानी इन्टेक, विद्यालय तथा स्वास्थ्य चौकी जस्ता सार्वजनिक आयोजनाहरूको विपद् संवेदनशीलता मूल्याङ्कन र अनिवार्य ५-१०% रोकथाम तथा बायो-इन्जिनियरिङ बजेट व्यवस्थापन।
- **वातावरण तथा नदीजन्य खानी नियमन (Riverbed Mining & IEE):** नदीजन्य पदार्थ (बालुवा, गिट्टी, ढुङ्गा) को अनियन्त्रित दोहन रोक्न स्वीकृत IEE कोटा अनुगमन, क्रसर नियमन र सामुदायिक वन जलाधार संरक्षण।
- **विपद् प्रतिकार्य तथा पूर्वसूचना (Early Warning & DRRM Hub):** स्वचालित वर्षा तथा जलसतह सेन्सर, प्रत्यक्ष क्यामेरा, आपत्कालीन SMS/साइरन ब्रोडकास्ट, राहत गोदाम मौज्दात र सुरक्षित आश्रयस्थल व्यवस्थापन।

## 💡 नेपालमा विपद् जोखिम न्यूनीकरणका उत्तम उपाय तथा सिफारिसहरू (Strategic Recommendations)

### १. बहुक्षेत्रीय जोखिम मूल्याङ्कनको वैज्ञानिक सूत्र (MSRA Methodology)
विपद् व्यवस्थापन ऐन २०७४ र सेन्डाई फ्रेमवर्क अनुसार जोखिम निर्धारण निम्न सूत्रमा आधारित हुन्छ:
$$\text{Risk (जोखिम)} = \frac{\text{Hazard (प्रकोप)} \times \text{Exposure (प्रकटीकरण)} \times \text{Vulnerability (संवेदनशीलता)}}{\text{Capacity (क्षमता/तयारी)}}$$
- **प्रकोप (Hazard):** बाढी, पहिरो, भूकम्प, आगलागी, हिमपहिरोको सम्भाव्यता र तीव्रता।
- **प्रकटीकरण (Exposure):** जोखिम क्षेत्रभित्र रहेका मानव बस्ती, घरधुरी, सडक, पुल र विद्यालयहरूको संख्या।
- **संवेदनशीलता (Vulnerability):** कच्ची संरचना, गरिबी, उमेर समूह (बालबालिका/वृद्धवृद्धा) तथा पूर्वसूचना अभाव।
- **क्षमता (Capacity):** पक्की आश्रयस्थल, राहत मौज्दात, तालिमप्राप्त उद्धार टोली र स्थानीय विपद् कोष।

### २. जोखिमयुक्त बस्ती पहिचानका प्राविधिक मापदण्ड (Settlement Risk Identification)
- **भौगोलिक मापदण्ड:** ३० डिग्रीभन्दा बढी भिरालो जमिन, गेग्रानयुक्त कमजोर भौगर्भिक बनावट वा विगतमा पहिरो खसेको स्थान।
- **नदी तटीय मापदण्ड:** उच्च जलसतह (High Flood Level) बाट १०० मिटर बफरभित्र रहेका तटीय बजार तथा बस्तीहरू।
- **हिमनदी ताल (GLOF):** पाँचपोखरी तथा हिमाली जलाधारबाट आउने गेग्रान बहावको प्रत्यक्ष मार्ग।
- **कार्यनीति:** 
  - अति उच्च जोखिममा रहेका बस्तीलाई सुरक्षित स्थानमा **सामूहिक एकीकृत बस्ती विकास** गरी स्थानान्तरण गर्ने।
  - मध्यम जोखिम भएका स्थानमा **बायो-इन्जिनियरिङ (उत्तिस, बाँस, अम्रिसो वृक्षारोपण)** र ग्याबियन वाल लगाउने।

### ३. पूर्वाधार आयोजनामा विपद्-जलवायु स्क्रिनिङ (Disaster-Resilient Infrastructure)
- **अनिवार्य जोखिम परीक्षण:** कुनै पनि सडक वा भवन निर्माण गर्नुपूर्व ३डी/जीआईएस डिजिटल ट्विनमा जोखिम तह (Risk Layer Overlay) रुजु गर्नुपर्ने।
- **१०% रोकथाम बजेट नियम:** उच्च जोखिम क्षेत्रमा पर्ने सडक वा पुल आयोजनामा कुल लागतको कम्तीमा ५ देखि १० प्रतिशत बजेट अनिवार्य रूपमा पानी निकास (Drainage), टेवा पर्खाल र बायो-इन्जिनियरिङका लागि छुट्याइनुपर्ने।
- **Build Back Better (BBB):** विपद्पछि पुनःनिर्माण गरिने पूर्वाधारहरू भूकम्प र बाढी प्रतिरोधी मापदण्डअनुसार मात्र निर्माण गर्ने।

### ४. नदीजन्य खानी तथा IEE नियमन (Riverbed Mining Regulation)
- मेलम्ची तथा अन्य नदी जलाधारमा बाढी र पुल कटानको मुख्य कारण अनियन्त्रित बालुवा/गिट्टी दोहन हो।
- **डिजिटल नियमन:**
  1. खानी क्षेत्रको चारकिल्ला GPS कोअर्डिनेट तोकी सोभन्दा बाहिर उत्खनन गर्न पूर्ण रोक लगाउने।
  2. IEE स्वीकृत कोटाभन्दा बढी उत्खनन रोक्न डिजिटल परिमाण मापन तथा तौलपुल (Weighbridge) प्रणाली लागू गर्ने।
  3. वर्षायाम (असार १ देखि भदौ मसान्तसम्म) नदीजन्य पदार्थ उत्खननमा पूर्ण प्रतिबन्ध लगाउने।
  4. नदीको मुख्य धारबाट ५० मिटर र पक्की पुलबाट ५०० मिटरभित्र कुनै पनि उत्खनन गर्न नदिने।

## 🛠️ प्रविधि संरचना (Technology Stack)

- **Frontend:**
  - React 19, TypeScript, Vite
  - GIS Mapping: Leaflet, React-Leaflet, GeoJSON Spatial Layers
  - Analytics & Charts: ECharts, Chart.js
  - Icons: Lucide React
  - Styling: Modern CSS Variables, Custom Glassmorphism Theme
- **Backend:**
  - Python 3.11+, FastAPI (Asynchronous REST API)
  - ORM: SQLAlchemy, GeoAlchemy2
  - Spatial Engine: Shapely, PostGIS
  - Multi-Tenant Middleware (Subdomain & Header based)
  - Authentication: JWT (Access & Refresh tokens) with RBAC
- **Database & Deployment:**
  - PostgreSQL 15 with PostGIS spatial extension
  - Docker & Docker Compose
  - PWA Support for Offline Field Operations

## 🚀 स्थापना तथा सञ्चालन विधि (Getting Started)

### १. ब्याकइन्ड सञ्चालन (FastAPI Backend)
```bash
cd fastapi-backend
python -m venv venv
# Windows:
.\venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
uvicorn main:app --reload --port 3001
```
*API स्वैगर डकुमेन्टेसन: `http://localhost:3001/docs`*

### २. फ्रन्टइन्ड सञ्चालन (React Frontend)
```bash
cd frontend
npm install
npm run dev
```
*ब्राउजरमा खोल्नुहोस्: `http://localhost:5173` (वा Vite ले देखाएको पोर्ट)*

### ३. डकर मार्फत एकैपटक सञ्चालन (Docker Compose)
```bash
docker compose up -d --build
```
